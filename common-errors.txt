ANADROMOUS UDP SOCKET BUFFER LIMITS

Anadromous requests 16 MiB Linux UDP send and receive socket buffers. Linux may
clamp those requests to net.core.wmem_max and net.core.rmem_max. Inspect the
limits on both bridge endpoints with:

sysctl net.core.wmem_max net.core.rmem_max

If they are below the transport request, choose limits appropriate for the host
and workload. For example, these temporary settings provide 32 MiB of room:

sudo sysctl -w net.core.wmem_max=33554432
sudo sysctl -w net.core.rmem_max=33554432

Persist changes through the operating system's normal sysctl configuration only
after validating memory use. SBMaxRecieveBufferSize is a separate per-stream
application buffer and does not configure the Linux UDP socket buffers.
